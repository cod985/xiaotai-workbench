安装到手机桌面

安卓：点下方按钮，或用浏览器菜单「添加到主屏幕 / 安装应用」。iPhone：用 Safari 打开本页 → 底部分享按钮 → 「添加到主屏幕」。安装后像普通 App 一样从桌面图标打开，支持离线使用。

云端同步（Upstash Redis + AES 加密）
数据在本机用 AES-GCM 加密后才上传，服务器只存密文。多台设备填入相同的地址、令牌和密码即可共享数据。免费申请：upstash.com → 创建 Redis 数据库 → 复制 REST URL 和 Token。
